Five identities,
one grid

Five palettes across six PowerPoint files, and that is the only thing separating them. Same 1440 × 810 canvas, same nineteen named layouts, same type scale, same standing furniture. Restyling a deck from one to another is a master swap, not a rebuild — which is why the differences below fit in a table, and everything the templates share is written out as prose underneath it.

what differs

The palettes, side by side

Every colour in the system, grouped by the band it belongs to — 60% field, 30% ink, 10% accent — with its contrast against its own template's page. A ratio is only meaningful against the surface it sits on, so each column is measured against its own field, never against a common white. derived marks a value that was not in the source palette: it was walked down or up its own hue until it cleared the gate in the role it was failing.
shared · type

One scale, and a font problem worth naming

Arial for Latin, 微軟正黑體 for 中文, in every template. Bold is the only weight variation — no italics, no letter-spacing tricks, no all-caps runs longer than three words. The sizes are on the 1440pt canvas; on a conventional 960pt canvas they are two-thirds of these numbers, which is why the upstream OfficeCLI rule of ≥36pt titles does not apply here and is overridden on purpose. These are dense documents that get read on a laptop, not projected.

微軟正黑體 ships with Windows only. macOS does not have it and substitutes — PingFang TC is the close equivalent, Heiti TC on older systems — and no browser has it at all. A .pptx run carries exactly one latin face and one east-asian face, with no fallback list, so the decks set latin=Arial, ea=微軟正黑體 and let PowerPoint on macOS do the substitution. shared · layouts

Nineteen named layouts

Same names, same indices, same geometry in every template, so --layout 'Data Table' resolves anywhere. The five shaded below carry their own furniture instead of the standing set: Cover, Section Divider and Closing are full-bleed accent; Quote and Blank ship deliberately bare.

Each template ships a catalogue at references/layout-catalogue/<name>-layouts.pptx — one slide per layout with every placeholder labelled by index and geometry, plus a palette page and this type table, generated from the same source as this page.

shared · gates

Four things that must pass

The first three are machine-checkable and none of them reads the argument. The fourth is the one that catches a deck that is correct and still says nothing.

Formatting

officecli view deck.pptx issues

Overflow, collided shapes, stale fields. Must be zero.

Colour

python3 scripts/contrast.py --check

Every token in every palette is present in its .pptx, and every ratio in the docs is regenerated rather than typed.

Content

python3 scripts/check_deck.py deck.pptx --palette '…'

Prints the title column to read as one argument. Fails on an unreplaced placeholder, a title promising a number its body contradicts, a wrong typeface, an off-palette colour. Warns on the assembly tells.

A reader who wasn't there

Agent → read this deck cold

Jumps in the logic, a title that disagrees with its own figure, a page that restates an earlier one. No machine sees these, and neither does the person who wrote the deck.

honesty

What is measured, and what is not

Sampled

ANA Blue came out of the corporate decks by frequency analysis. Yukima came off a source board. SKS Dark was pixel-read from two reference comps. Reiser Warm's field and coral are its own.

Read by eye

SKS Blue is the exception and says so on its own page. The Figma file is not shared with the account wired into this toolchain, and its prototype renders to a WebGL canvas whose buffer cannot be read back — so nothing could be measured. Expect each channel within a few points.

Derived

Yukima needed two inks because its source palette contained none: its darkest colour was 4.92:1. Reiser Warm needed one ink and nine text-safe variants. SKS Dark needed three. Each is a value-shift of a source colour, same hue, moved only as far as the gate required.

The gate

4.5:1 below 24px, 3.0:1 at or above. Ratios here are computed from the hexes, never estimated, and they are measured against each template's own field — never a common white, which would flatter the dark ones and punish nothing.
